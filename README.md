## 🚀 Selected Engineering Work

### 1. ProsHQ | Marketplace & Service Platform

A marketplace platform connecting clients with service providers, enabling users to discover services, create tasks, manage applications, communicate and handle payments through an integrated wallet and escrow system.

Previously known as TheBestPriceNG, ProsHQ represents the platform's evolution and continued development.

**Key Engineering Contributions:**

- Developed and integrated frontend features using React, TypeScript and Tailwind CSS.
- Built and integrated REST APIs using Node.js and Express.js.
- Implemented wallet funding, withdrawals and transaction management.
- Integrated Paystack and BudPay for payment processing.
- Worked on escrow workflows, including fund locking and release mechanisms.
- Implemented transaction reference validation and duplicate-payment prevention.
- Worked on authentication, authorization and role-based access control.
- Integrated real-time communication and notifications using Socket.io.
- Worked on file uploads and third-party service integrations.
- Contributed to deployment, environment configuration and production troubleshooting.

**Technical Stack:** React, TypeScript, Tailwind CSS, Node.js, Express.js, MongoDB, Mongoose, Socket.io, Paystack, BudPay.

**Engineering Focus:** Full-stack development, backend architecture, payment infrastructure, financial workflows, API integration and production reliability.
